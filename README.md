# Inkvio

Inkvio is a smart print shop management SaaS for handling customer orders, quotations, design approvals, print queues, customers, inventory, payments, and reports.

## Current MVP

- Responsive print-shop dashboard
- Job order management
- Messenger / walk-in / phone / online-form order sources
- Quick tarpaulin quotation calculator
- Design queue and print queue views
- Customer history
- Products & services catalog
- Inventory overview
- Payment summary
- Reports and operational insights
- Settings panel
- Local browser persistence for demo data

## Deployment

This repository includes a GitHub Pages workflow. Once Pages is configured to use **GitHub Actions**, pushes to `main` deploy automatically.
